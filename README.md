# Task 1: CGPA Calculator (C++)

## Description
A console-based CGPA Calculator that:
- Takes number of courses as input
- Accepts grade (0-10 scale) and credit hours for each course
- Calculates total credits and total grade points
- Computes Semester GPA / CGPA
- Displays a formatted table of results

## How to Compile & Run
```bash
g++ cgpa_calculator.cpp -o cgpa
./cgpa
```

## Features
- Input validation for number of courses, grades, and credits
- Clean tabular output
- Grade Points = Grade × Credit Hours
- CGPA = Total Grade Points ÷ Total Credits
